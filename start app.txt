--------------------------------------------------------------------------------
STEP 1: SET POWERSHELL EXECUTION POLICY (ONE-TIME SETUP)
--------------------------------------------------------------------------------
If Windows blocks PowerShell script execution (error: "running scripts is disabled 
on this system"), run the following command in PowerShell:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Alternatively, to bypass execution policy for the current session only:

    Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

Press [Y] or [A] (Yes to All) when prompted to confirm.


--------------------------------------------------------------------------------
STEP 2: ACTIVATE THE VIRTUAL ENVIRONMENT (VENV)
--------------------------------------------------------------------------------

A) IN POWERSHELL:
-----------------
    .\venv\Scripts\Activate.ps1

    (Once activated, you will see "(venv)" at the start of your terminal prompt)


B) IN COMMAND PROMPT (CMD):
---------------------------
    .\venv\Scripts\activate.bat


C) TO DEACTIVATE LATER:
-----------------------
    deactivate


--------------------------------------------------------------------------------
OPTION 1: STANDALONE EXECUTABLE (NO PYTHON REQUIRED ON TARGET PC)
--------------------------------------------------------------------------------
A completely self-contained executable is already compiled:
    SarvatraAI.exe (22.8 MB)

To deploy on any air-gapped PC:
  1. Simply copy 'SarvatraAI.exe' to any folder on the target machine.
     (The target machine DOES NOT need Python or pip installed!)
  2. Double-click 'SarvatraAI.exe'.
  3. It will automatically connect to local Ollama, verify the database,
     auto-create the 'admin' account, and launch http://127.0.0.1:8000 in your browser.

To recompile the .exe in the future:
  Double-click:
      build_exe.bat


--------------------------------------------------------------------------------
OPTION 2: PYTHON SOURCE & WHEELS BUNDLE (BUILD & INSTALL)
--------------------------------------------------------------------------------

A) TO BUILD THE ZIP BUNDLE (ON CONNECTED/DEV MACHINE):
------------------------------------------------------
Double-click or run:
    build.bat

This will:
  1. Download all required Python wheel packages into 'wheels/'.
  2. Create 'Ollama_Chat_AirGapped_Bundle.zip' excluding venv, database, 
     and temporary files.


B) TO INSTALL ON THE AIR-GAPPED TARGET MACHINE:
-----------------------------------------------
1. Copy 'Ollama_Chat_AirGapped_Bundle.zip' to the air-gapped machine.
2. Extract the ZIP into your desired destination folder.
3. Double-click or run:
       install.bat

This will:
  - Create a new virtual environment ('venv') automatically.
  - Install all dependencies 100% offline from the bundled 'wheels/' directory.
  - Apply migrations and auto-create the default admin account.

4. To launch the app, double-click:
       run_app.bat


--------------------------------------------------------------------------------
STEP 3: RUN THE APPLICATION
--------------------------------------------------------------------------------

METHOD 1: ONE-CLICK LAUNCHER (RECOMMENDED)
-----------------------------------------
Double-click:
    run_app.bat

(This automatically checks Python 3.7.9, checks Ollama models, runs migrations, 
opens your browser to http://127.0.0.1:8000, and starts the server).


METHOD 2: MANUAL COMMAND LINE
-----------------------------
1. Activate the venv (as shown in Step 2).
2. Start the Django development server:

    python manage.py runserver 127.0.0.1:8000

3. Open your browser and navigate to:
    http://127.0.0.1:8000
